Подключение backend

После install.ps1 или install.sh выбери connection.json из каталога установки. Этот файл содержит ключ локального API: храни его у себя.

Windows: %LOCALAPPDATA%\AmneziaBrowser\connection.json
Linux: ~/.config/amnezia-browser/connection.json

Запуск и восстановление выполняются менеджером backend. Повторное скачивание ядра для этого не нужно.

Windows PowerShell: & "$env:LOCALAPPDATA\AmneziaBrowser\backend.ps1" -Action Restart

Linux: ~/.local/lib/amnezia-browser/backend.sh restart

Доступные действия: Start / Stop / Restart / Status / Check / Run в PowerShell; start / stop / restart / status / check / run в Linux. Check проверяет HTTP через настоящий SOCKS-порт.

Маршруты и приватность

Эти настройки действуют на профиль, включая наследуемые настройки incognito. Ограничение WebRTC может изменить работу звонков. Когда VPN-правил нет или управление выключено, расширение освобождает свои proxy/privacy-настройки. При активном PAC остальные домены идут Direct. Это не системный VPN и не гарантия отсутствия всех сетевых утечек.

Правила доменов

Правило охватывает домен и его поддомены. Более специфичное правило имеет приоритет. VPN для YouTube и Discord включает набор связанных доменов; явное правило для того же домена имеет приоритет над набором.

ДоменМаршрутДействия

Импорт объединяет правила; совпадающие домены заменяются значениями из файла. Ключ подключения не экспортируется.

Диагностика и обновления

Перед отправкой просмотри диагностику: в ней могут быть домены из правил и ошибок. Приватный ключ VPN и ключ controller API не включаются.

Для удаления сначала выключи управление маршрутами здесь, затем удали расширение и запусти uninstall.ps1 или uninstall.sh.
