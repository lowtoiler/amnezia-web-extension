# Amnezia Browser

Version 1.

Browser extension for routing selected websites through AmneziaVPN using mihomo.

## Install

### Windows

```powershell
.\install.ps1

Select your .conf file, then load the extension folder in:

chrome://extensions

Enable Developer mode → Load unpacked.

Import the generated connection.json in extension settings.

Linux
chmod +x install.sh uninstall.sh
./install.sh

Then load the extension folder in Chrome.

Features
Per-site Direct / VPN routing
AmneziaWG support
Local SOCKS proxy
Backend status and health checks
Automatic backend restart
Import / export rules
Updates
