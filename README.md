# Amnezia Browser

Version 1.

## How to use

### Windows

1. Run `./install.ps1` in PowerShell.
2. Select your Amnezia Premium `.conf` file.
3. Open `chrome://extensions`.
4. Enable Developer mode.
5. Click **Load unpacked** and select the `extension` folder.
6. Open the extension on any website and choose **Direct** or **VPN**.

### Linux

```bash
chmod +x install.sh uninstall.sh
./install.sh
```

Then open `chrome://extensions`, enable Developer mode, click **Load unpacked**, select the `extension` folder, and choose **Direct** or **VPN** for the current website.
